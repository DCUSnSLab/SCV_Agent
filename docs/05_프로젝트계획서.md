`~/data/rosbag2_2026_01_21-18_41_02` (55 GB, 550초, 290,275 msgs) 기준 실측. 01 문서 §3의 예상값을 실제 로봇(Hunter 플랫폼) 토픽으로 갱신한다.

|---|---|---|---|---|
| `/odom_bae` | `nav_msgs/msg/Odometry` | ~50 Hz | rate 다운샘플 2 Hz | 상태 |
| `/hunter_status` | `hunter_msgs/msg/HunterStatus` (커스텀) | ~50 Hz | deadband + 상태변화 시 즉시 | 상태/이벤트 |

- 대역폭(`ros2 topic bw` 상당) 실측은 M3 착수 시 rosbag 재생으로 측정하여 본 표를 갱신한다.
- GPS(`NavSatFix`), 배터리(`BatteryState`), diagnostics, 전역 경로(`nav_msgs/Path`)는 본 bag에 없음 — 실 로봇 확인 후 추가.

## 3. 마일스톤 WBS

> 순서 고정: 업링크(M1~M4) 완성·검증 후 다운링크(M5) 진입. M5 시작 전 NFR-7(안전 조항) 재독 필수.

### M1 — 골격 + 최소 종단 연결

**목표**: 아키텍처의 뼈대(인터페이스+레지스트리, YAML 구성)를 세우고 단일 토픽이 종단으로 흐르는 것을 증명한다.

| # | 작업 | 산출물 |
|---|---|---|
| 1.1 | colcon 패키지 골격 (`fta_agent`, `fta_tools`, ament_python) | package.xml, setup.py |
| 1.2 | 범용 레지스트리 + `ISampler`/`ICodec`/`ITransport` ABC | `core/registry.py`, `samplers/base.py`, `codecs/base.py`, `transports/base.py` |
| 1.3 | ConfigLoader — YAML 로드 + 스키마 검증(jsonschema), 오류 시 즉시 종료+원인 명시, `${ENV}` 치환 | `config/loader.py`, `config/schema.py` |
| 1.4 | Envelope (CBOR, version 필드 포함 — 서버 프로젝트와의 계약) | `core/envelope.py` |
| 1.5 | 파이프라인: generic subscription(raw CDR) → 입력큐 → 워커(샘플→인코딩→봉투) → 우선순위큐. 콜백에서 인코딩·I/O 금지 | `core/pipeline.py`, `core/subscription_manager.py`, `core/priority_queue.py` |
| 1.6 | `passthrough` 샘플러 + `cbor` 코덱 + `MqttTransport`(paho v5, LWT, `fleet/{robot_id}/...` 네임스페이스) | `samplers/passthrough.py`, `codecs/cbor_codec.py`, `transports/mqtt_transport.py` |
| 1.7 | UplinkManager (M1: 단순 큐 드레인 발행) | `core/uplink_manager.py` |
| 1.8 | 테스트 리시버: mosquitto 구독 → envelope 디코딩 → jsonl 기록 + 통계(로봇별 msg 수/bw/지연) | `fta_tools/test_receiver.py` |
| 1.9 | 단위 테스트 (레지스트리, 설정 검증, envelope 왕복, 샘플러) | `test/` |

**완료 기준**: 가상 발행 `/odom` 토픽이 리시버 jsonl에 기록됨 (실행 로그로 증명)

## 5. 리스크 및 대응

| 리스크 | 영향 | 대응 |
|---|---|---|
| Python 성능 — NFR-1(CPU 20%/512MB) 미달 가능성 | 중 | 콜백 최소화·raw CDR 패스스루로 역직렬화 회피. M3 대역폭 리포트와 M6 성능 테스트에서 조기 측정, 병목 구성요소만 선택적 최적화(멀티프로세스/C 확장) |
| `hunter_msgs` typesupport 개발 머신 부재 | 저 | CDR passthrough 업링크는 영향 없음. M5에서 "미지원 인터페이스 보고"의 음성 테스트 케이스로 활용. 실 로봇 배포 전 msg 패키지 확보 |
| GIL로 인한 압축·인코딩 지연 | 중 | Bulk 코덱(M3)은 zstd/OpenCV가 GIL 해제하는 C 라이브러리라 실질 영향 제한적. 측정 후 판단 |
| deadband/event 샘플러의 CDR 역직렬화 비용 | 저 | 해당 파이프라인만 타입 로드. 고주기 토픽에는 rate 우선 적용 |
| 개발 머신에 실 로봇 없음 | 저 | rosbag 재생(`~/data`)으로 전 마일스톤 검증 가능 |
| LTE/CGNAT 환경 미검증 | 중 | M4 단절 테스트는 로컬 네트워크 차단으로 모사. 실망 검증은 실 로봇 파일럿에서 |

## 6. 서버 프로젝트와의 계약 (변경 시 상호 합의 필요)

- 레지스트리 항목 스키마 + retained 발행 포맷 (02 문서 §3.11)
- 명령/응답 envelope (FR-9.4, FR-9.7)
