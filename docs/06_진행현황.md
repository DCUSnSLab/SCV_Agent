### M2 검증 증빙 (2026-07-24)

```
파이프라인          수신   실효 Hz   평균 지연   결과
odom  (50Hz 발행)   22건   1.97 Hz   0.37 ms   rate 2Hz 다운샘플 ✓
imu   (50Hz 발행)   54건   4.74 Hz   0.93 ms   rate 5Hz 다운샘플 ✓
battery (5Hz 발행)   2건       —     0.35 ms   deadband — 0.8→0.9 변화 2건만 통과 ✓
vehicle_estop        2건       —     0.33 ms   event changed — 초기 false + 변화 true,
                                               fleet/r01/event/* 채널 ✓
planned_path         1건       —     0.25 ms   에이전트 기동 전 latched 발행분을
                                               transient_local 구독으로 수신 ✓
전체 seq 결손 0
```

부수 수정: SIGTERM 종료 시 ExternalShutdownException 트레이스백 제거 (정상 종료 경로 처리).
